# Changelog

## 0.2.0 — 23 October 2026

- Added an integrated browser workspace served by FastAPI, with dashboard,
  contacts, companies, sales pipeline, follow-up tasks, activity timeline, and
  explicit context preview and confirmation for mock summaries.
- Added deal/task/activity CRUD, filtering, decimal deal values, currency grouping,
  timestamp validation, relationship constraints, and persistent stage history.
- Added automatic migration from the foundation database and JSON backup export.
- Added `python -m deedee` as the local startup command.
- Verified 16 backend tests, a DOM-to-live-API UI check, and a full Chromium
  browser workflow including desktop/mobile screenshots, persistence, and backup download.
